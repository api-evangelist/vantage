# Vantage

> Vantage is a cloud cost observability and FinOps platform. These docs cover provider integrations (AWS, Azure, GCP, Kubernetes, Snowflake, OpenAI, and more), Cost Reports, budgets, Autopilot, the Vantage MCP and FinOps Agent, the Vantage API, and the Terraform provider.
